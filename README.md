## 1. 프로젝트 목적 및 배경

업무나 공부에 집중하다 보면 무의식적으로 **손톱이나 손가락을 물어뜯는 습관**이 반복되는 경우가 있습니다.  
(실제로 저는 너무 많이 뜯은 나머지 손가락이 상당히 너덜너덜합니다...🥲)

`please-stop-biting`은 이러한 행동을 사용자가 직접 인지하지 못하는 순간에도 카메라를 통해 감지하고,
즉시 경고를 제공하여 행동을 멈출 수 있도록 돕는 것을 목표로 합니다.

스스로의 습관을 교정하기 위해 시작한 개인 프로젝트이지만, 비슷한 습관으로 스트레스를 받는 누구나 사용할 수 있도록 개발하는 것을 목표로 합니다.
**따라서 오픈소스로 공개하며, 필요에 따라 자유롭게 수정하거나 확장할 수 있습니다!**

## 2. 주요 기능

*아래 내용은 초기 구현 목표이며, 개발 진행 상황과 발생하는 이슈에 따라 변경될 수 있습니다.*

- Mac 카메라를 이용한 실시간 영상 입력
- 손 및 얼굴 위치 인식
- 손가락과 입 주변의 거리 기반 행동 감지
- 일정 시간 이상 물어뜯는 행동이 지속될 경우 경고 표시
- 일반적인 얼굴 접촉 행동과 물어뜯기 행동을 구분하기 위한 오탐 방지 로직
- 카메라 영상은 저장하지 않고 로컬 환경에서 실시간 처리

---

## 3. 동작 흐름

*아래 내용은 초기 구현 목표 기준의 흐름이며, 개발 진행 상황과 발생하는 이슈에 따라 변경될 수 있습니다.*

1. Mac 카메라를 통해 실시간 영상을 입력받습니다.
2. 영상에서 손과 얼굴의 주요 랜드마크를 감지합니다.
3. 손가락 위치와 입 주변 영역의 거리를 계산합니다.
4. 손가락이 입 주변에 일정 시간 이상 머무르는지 확인합니다.
5. 물어뜯는 행동으로 판단되면 경고 화면을 표시합니다.
6. 행동이 종료되면 다시 감지 상태로 돌아갑니다.
