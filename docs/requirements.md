# Requirements

## 1. 프로젝트 목표

`please-stop-biting`은 Mac 카메라를 이용하여 사용자가 손톱이나 손가락을 입으로 물어뜯는 행동을 실시간으로 감지하고, 해당 행동이 감지되었을 경우 경고를 제공하는 것을 목표로 한다.

프로그램은 사용자가 업무나 공부를 하는 동안 백그라운드에서 실행될 수 있어야 하며, 사용자의 행동을 방해하지 않는 범위에서 지속적으로 감지를 수행한다.


## 2. 감지 대상

다음 행동을 감지 대상으로 정의한다.

- 손톱을 입으로 물어뜯는 행동
- 손가락 끝이나 손가락 주변 피부를 입으로 물어뜯는 행동
- 손가락을 입 주변에 가져간 상태에서 물어뜯는 행동이 일정 시간 지속되는 경우


## 3. 감지 제외 대상

다음과 같은 일반적인 행동은 가능한 한 물어뜯는 행동으로 판단하지 않아야 한다.

- 턱 괴기
- 얼굴 만지기
- 입 주변 만지기
- 손으로 입 가리기
- 물이나 음료 마시기
- 음식 먹기
- 키보드 및 마우스 사용
- 손톱이나 손가락을 눈으로 확인하는 행동


## 4. 주요 기능 요구사항

### 4.1 카메라 입력

- Mac에 연결된 카메라를 통해 실시간 영상을 입력받는다.
- 프로그램 실행 중 지속적으로 프레임을 처리할 수 있어야 한다.


### 4.2 손 및 얼굴 인식

- 영상에서 사용자의 손 위치를 인식한다.
- 영상에서 사용자의 얼굴 및 입 주변 위치를 인식한다.
- 손가락과 입 주변의 상대적인 위치를 확인할 수 있어야 한다.


### 4.3 물어뜯기 행동 판별

- 손가락이 입 주변에 접근했는지 확인한다.
- 단순 접촉과 물어뜯기 행동을 구분하기 위해 일정 시간 동안의 행동을 확인한다.
- 구체적인 판별 조건과 임계값은 실제 테스트를 통해 결정한다.


### 4.4 경고

물어뜯는 행동이 감지되었을 경우 사용자에게 즉시 경고를 제공한다.
초기 버전에서는 다음 방식 중 하나 이상을 사용한다.

- 경고 메시지 표시
- 화면 위에 경고 오버레이 표시

구체적인 UI와 경고 방식은 구현 과정에서 결정한다.


## 5. 개인정보 및 데이터 처리

- 카메라 영상은 행동 감지를 위한 실시간 처리 목적으로만 사용한다.
- 카메라 원본 영상을 저장하지 않는다.
- 영상 데이터를 외부 서버로 전송하지 않는다.
- 모든 영상 처리는 사용자의 로컬 환경에서 수행하는 것을 원칙으로 한다.


## 6. MVP 범위

1차 버전에서는 다음 기능까지 구현하는 것을 목표로 한다.

- Mac 카메라 입력
- 손 위치 인식
- 얼굴 및 입 위치 인식
- 손가락과 입 위치를 이용한 기본적인 물어뜯기 행동 판별
- 행동 감지 시 경고 출력
- macOS 환경에서 실제 실행 가능한 프로그램 제공


## 7. MVP 제외 범위

초기 버전에서는 다음 기능을 구현 대상에서 제외한다.

- 딥러닝 기반 사용자 행동 학습
- 사용자별 행동 패턴 학습
- 감지 기록 통계 및 대시보드
- 사용자 계정
- 서버 및 클라우드 연동
- 모바일 및 Windows 등 다른 OS 지원


## 8. 추후 결정 사항

다음 항목은 실제 구현 및 테스트 과정에서 결정한다.

- 물어뜯기 판단에 필요한 최소 지속 시간
- 손가락과 입 사이의 거리 임계값
- 반복 움직임을 판별하는 방법
- 경고 UI 형태
- 오탐 방지를 위한 추가 조건
- 백그라운드 실행 방식
